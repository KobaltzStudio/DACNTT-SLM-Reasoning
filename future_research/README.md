# P1 extensions — FUTURE_WORK

The current experiment ranks capability deficits or combines those deficits with P2 learnability. Capability labels come from the frozen taxonomy and the approved Gold release. The repository uses seven dimensions (addition, subtraction, multiplication, division, percentage, fraction and ratio). Verify names and support from the current checked Gold and capability manifests before registering any new study.

The proposed research asks whether targeted training on one capability improves a distinct downstream capability. No directed edges, transfer outcomes or graph-guided training results have been established in this handoff. The modules and protocol of Run A and Run B contain no graph-guided branch.
