# DACNTT - SLM Reasoning

Research and implementation repository for the DACNTT project.

## Research Direction

This project investigates Small Language Models (SLMs),
reasoning capability, and knowledge distillation.

## Baseline

Current baseline:

- Dataset: GSM8K
- Teacher accuracy: 95.00% on 20-sample smoke test
- Student accuracy: 35.00% on 20-sample smoke test
- Accuracy gap: 60 percentage points
